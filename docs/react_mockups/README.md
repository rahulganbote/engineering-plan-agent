# React UI Mockups

High-fidelity mockup PNGs referenced by the React migration plan. These are
the visual targets that Sprint 1 onward implements against.

## Files

| File | What it shows | Used in plan |
|---|---|---|
| `brd_upload_hub_spoke_glowing_mockup_01.png` | Landing page: dropzone, demo warning, hub-and-spoke pipeline diagram | Sprint 2 (Ingestion landing view) |
| `artifacts_generated_slate_mockup_02.png` | Active workstation: timeline stepper, log console, artifact tabs, HITL gate | Sprint 4 (Artifact canvas) + Sprint 5 (HITL gate) |
| `settings_theme_selector_mockup_03.png` | Premium Settings view with Liquid Glass + theme toggle | **DEFERRED to v2** (kept for reference only) |


## Theme & decisions

- v1 ships **dark slate everywhere**. Both the landing and workstation mockups
  already target this palette.
- The Settings mockup (file 3) covers the Liquid Glass + theme toggle surface
  that is **deferred to v2**. The PNG stays here so the v2 plan has a visual
  reference when those features come back.

See [`../../react_migration_plan.md`](../../react_migration_plan.md) for the
full sprint plan and decisions log.
