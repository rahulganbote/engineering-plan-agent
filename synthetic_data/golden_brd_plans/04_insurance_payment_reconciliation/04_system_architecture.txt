## Pattern Selection
pattern: Batch data pipeline with workflow service
pattern_justification: |
  Daily finance reconciliation is batch-oriented with heavy audit needs; streaming microservices were rejected because real-time settlement is out of scope. Team size is assumed to be 5-8 engineers, which is enough for clear component ownership without creating unnecessary platform overhead. The primary NFR driver is Process 1 million payment lines in <= 45 minutes. The architecture respects compliance constraints for HIPAA, SOX, SOC 2, NACHA file handling.

## Components

    responsibility: Manages analyst review and approvals.
    technology: Django REST Framework

  - name: Audit Evidence Store
    responsibility: Stores immutable run logs and approvals.
    technology: S3 Object Lock + PostgreSQL
    interfaces: [SQL, object API]
