## Pattern Selection
pattern: API-first modular commerce service
pattern_justification: |
  The return experience needs fast synchronous APIs and policy-rule ownership; event-driven processing remains for warehouse notifications. A full microservice split was rejected for MVP speed. Team size is assumed to be 5-8 engineers, which is enough for clear component ownership without creating unnecessary platform overhead. The primary NFR driver is Return eligibility and recommendations respond in <= 1.5 seconds P95. The architecture respects compliance constraints for PCI scope avoidance, consumer refund laws, SOC 2.

## Data Flow
